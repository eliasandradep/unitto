Captura de leads pelo site do cliente

Capture leads direto do{% if empresa and empresa.website %} site do cliente{% else %} site do cliente{% endif %} (cadastre o site em Configurações → Perfil da Empresa) colando o widget abaixo, ou integrando com um formulário próprio via o endpoint para desenvolvedores.

Widget (uso recomendado)

Cole esta linha em qualquer página do site do cliente (antes do fechamento de </body>). Ela adiciona um botão flutuante "Fale conosco" com um mini-formulário, incluindo a lista de serviços disponíveis. 

<script src="https://{{ base_domain }}/static/js/lead-widget.js" data-slug="{{ empresa.slug }}" async></script>
Para desenvolvedores (endpoint cru)

Prefere plugar num formulário de contato já existente no site? Aponte o action dele para: 

POST https://{{ base_domain }}/{{ empresa.slug }}/lead-capture

Campos aceitos (todos como application/x-www-form-urlencoded):

  • nome — obrigatório
  • telefone — obrigatório
  • servico — opcional
  • mensagem — opcional
  • _redirect — opcional, URL para onde redirecionar após o envio (formulário sem JavaScript)
